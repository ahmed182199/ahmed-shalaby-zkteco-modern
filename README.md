# World Clock

A responsive, dependency-free digital clock that displays the current time across multiple time zones.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Features

- Live hours, minutes, and seconds for multiple cities.
- Add/remove time zones with localStorage persistence.
- Search clocks and available time zones.
- Light/dark theme toggle.
- Responsive layout with no build step or external dependencies.
